# Техническое задание

## Проект: SSH-клиент на Avalonia

### 1. Общее описание

Разработка кроссплатформенного SSH-клиента с графическим интерфейсом на базе Avalonia UI.
Приложение должно обеспечивать удобное управление подключениями и работу с терминалом.

---

### 2. Основной функционал

#### 2.1. Сайдбар (панель подключений)

* Располагается в левой части интерфейса
* Содержит список сохранённых подключений
* Возможности:

  * Добавление нового подключения
  * Редактирование подключения
  * Удаление подключения
  * Выбор подключения для открытия

---

#### 2.2. Работа с вкладками

* При открытии подключения создаётся новая вкладка
* Каждая вкладка содержит:

  * Активное SSH-соединение
  * Терминал (консоль)
* Возможности:

  * Переключение между вкладками
  * Закрытие вкладки
  * Повторное открытие соединения

---

#### 2.3. Терминал

* Отображение вывода SSH в реальном времени
* Поддержка ввода команд пользователем
* Отправка команд на сервер
* Отображение результата выполнения

---

#### 2.4. История команд

* Отображается в отдельной панели (слева внутри вкладки)
* Содержит список ранее введённых команд

Функциональность:

* Добавление команды в историю после выполнения
* Повторный запуск команды по клику
* Удаление отдельной команды из истории
* Полная очистка истории

---

### 3. Пользовательский интерфейс

#### 3.1. Основная структура

* Левая панель:

  * список подключений (глобальный sidebar)
* Центральная область:

  * вкладки с активными сессиями
* Внутри вкладки:

  * слева — история команд
  * справа — терминал

---

### 4. Требования к системе

* Кроссплатформенность (Windows, Linux, macOS)
* Использование Avalonia UI
* Использование SSH-библиотеки (например SSH.NET)

---

### 5. Дополнительно (желательно)

* Поддержка авторизации по SSH-ключу
* Сохранение истории команд между сессиями
* Поиск по истории команд
* Горячие клавиши (например Enter, Ctrl+C)

---

### 6. Минимально жизнеспособный продукт (MVP)

* Добавление подключения
* Открытие подключения во вкладке
* Выполнение команд
* История команд с удалением и очисткой
